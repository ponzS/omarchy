# LightOS Omarchy 容器使用官方系统更新

## 背景

LightOS 容器由宿主提供内核、引导和 rootfs 生命周期。旧镜像固定了定制 Omarchy 包，却允许配套设置包升级，导致用户从官方更新入口更新时出现依赖冲突。

## 需求目标

已有实例和新建 Omarchy 容器的普通用户可以通过官方菜单或 `omarchy update` 更新官方稳定版软件包及适用迁移，不需要逐版本重打定制 Omarchy 包。更新不重建实例，不删除个人文件，并保留容器桌面的启动能力。容器不部署宿主引导、不管理宿主内核或创建整机快照。

## 范围

当前已有实例从定制 4.0.4 包迁移到官方包，以及此后新镜像创建的实例使用相同官方更新入口。LightOS 的 GPU、VT、登录和远程桌面集成保持独立。

## 非目标

不更新宿主系统，不自动重启宿主，不通过更换镜像标签替换已有实例 rootfs，不承诺所有未来上游变更无需兼容性维护。
