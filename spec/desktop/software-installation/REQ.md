# LightOS Omarchy 软件安装与基础应用

## 背景

LightOS 用户可以创建 Omarchy 实例并连接远程桌面，但原镜像缺少安装入口和应用启动项依赖的程序。安装菜单不能打开安装窗口，交互安装器报错后仍返回成功，多个应用快捷方式没有对应的程序。

## 需求目标

使用本 fork 镜像新建的 Omarchy 实例应能通过桌面菜单和终端安装普通软件与 AUR 软件。AUR 软件可以由普通用户构建，再按现有权限机制安装。

实例预装 Chrome，并默认用它打开网页和网页应用快捷方式。桌面同时提供 Foot、文件管理器、Neovim、图片查看器、视频播放器及 btop，用户无需先修复安装工具即可使用这些基础应用。

安装器遇到选择或安装失败时返回失败，不继续显示成功完成。首次用户配置保留已提供的默认浏览器。

## 范围

Linux x86_64 LightOS 容器镜像的运行依赖、基础应用、默认浏览器、交互安装入口和 GHCR 发布标签。

## 非目标

不引入 ISO 的内核、引导器、磁盘快照或硬件安装流程，不预装完整 ISO 的所有应用。不自动覆盖已有实例和用户偏好，不新增自动真机测试场景。正式新实例与远程桌面验收由开发者手工执行。
