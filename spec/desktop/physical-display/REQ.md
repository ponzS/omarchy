# Omarchy 物理桌面与其他实例共用显示器

## 背景

用户通过宿主机的 VT Manager 切到 Omarchy 后需要再次登录。进入桌面后，切到其他实例仍显示 Omarchy 或黑屏，影响其他桌面的使用。

## 需求目标

实例所有者启用显示接管后，通过 `hc vt switch` 切到 Omarchy，直接进入普通实例用户的桌面。切到其他实例时，Omarchy 释放显示和输入设备；切回时恢复原桌面，无需重新登录。

启动 Omarchy 实例和连接其远程桌面不改变当前物理桌面的归属。终端分配与切换由宿主机 VT Manager 管理，镜像只使用分配给该实例的终端。

## 范围

LightOS x86_64 Omarchy 镜像的物理桌面启动、普通用户自动登录、显示和输入设备释放及恢复；同时连接远程桌面的使用条件。

## 非目标

不修改宿主机 VT Manager，不增加容器全局终端权限，不重启其他实例的桌面服务。开发者手工验收，不新增自动真机测试场景。
